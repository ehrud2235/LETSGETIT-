# 마지막 배 — 2인 협동 3D 좀비 탈출

밤이 된 항구 도시에서 두 사람이 총을 들고 **마지막 배**가 있는 항구까지 빠져나가는 1인칭 협동 브라우저 게임입니다.
레프트 4 데드처럼 좀비 떼가 몰려오고, 길 안내 화살표 없이 **표지판·게시판·쪽지·멀리 보이는 불빛**을 보고 스스로 길을 찾아야 해요.
설치 없이 링크만 있으면 되고, PC(키보드+마우스)용입니다.

## 규칙

- 2명이 한 팀. 초대코드로 방을 만들어 같이 하거나, 혼자 연습할 수 있어요.
- 길은 알려주지 않습니다. 잠긴 문·무너진 다리·막힌 셔터를 만나면 주변을 뒤져 다른 길이나 열쇠·전원을 찾아야 합니다.
- 체력이 0이 되면 **쓰러지고**, 동료가 `E` 를 꾹 눌러 일으켜 줄 수 있어요. 쓰러진 채로 오래 있거나 **세 번째로 쓰러지면 죽습니다**.
- **한 명이라도 죽으면 맨 처음부터** 다시 시작합니다. (무기·구급상자·열린 문 전부 초기화)
- 총소리는 좀비를 부르고, 손전등에 비친 좀비는 나를 알아챕니다. 경보·발전기처럼 **시끄러운 장치를 켜면 떼가 몰려옵니다**.
- 문을 닫아 두면 좀비가 부수고 들어오는 데 시간이 걸려요 (영원히 막히지는 않습니다).
- 한 판 플레이 시간은 길을 처음 찾는 두 사람 기준 대략 25~40분입니다.

난이도: 쉬움 / 보통 / 어려움 — 좀비 공격력, 수, 쓰러진 뒤 버틸 수 있는 시간이 달라집니다.

## 조작

| 동작 | 키 |
| --- | --- |
| 이동 / 달리기 / 숙이기 | `W` `A` `S` `D` / 왼쪽 `Shift` / `C` 또는 `Ctrl` |

| 장전 | `R` |
| 무기 바꾸기 | `1` 주무기 · `2` 권총 · `4` 구급상자 · `Q` 직전 무기 · 휠 |

## 인터넷에 올리기 (Render 무료)

저장소 최상위의 `render.yaml` 블루프린트에 이 게임이 **`last-boat`** 라는 별도 서비스로 들어 있어요. 맞은편(방탈출)·물렁 난투와는 서버도 주소도 따로입니다.

- 이미 블루프린트로 다른 게임을 올렸다면: Render 대시보드 → **Blueprints** → 이 저장소 → **Sync** (또는 Manual Sync) 를 누르면 새 서비스가 추가됩니다.
- 직접 만들 때는: **New + → Web Service** → 이 저장소 → **Root Directory 에 `lastboat`** → Build `npm ci --omit=dev`, Start `npm start`, Health Check Path `/healthz`.

몇 분 뒤 `https://last-boat-xxxx.onrender.com` 같은 새 주소가 생깁니다.

서버는 **싱가포르**(한국에서 가장 가까운 Render 지역)로 설정돼 있어요. 지역은 서비스를 처음 만들 때만 정해지므로, 이미 미국(기본값 오리건)에 만들어 둔 `last-boat` 가 있다면 대시보드에서 그 서비스를 지우고 Blueprint 를 다시 Sync 해야 싱가포르로 옮겨집니다 (주소가 바뀔 수 있어요).

## 끊기거나 느릴 때

- 게임 중 `P` 를 누르면 FPS · 해상도 · 연결 방식 · 핑이 보여요.
- **해상도가 100% 보다 낮다** → 그 컴퓨터의 그래픽이 버거워서 자동으로 낮춘 것. 설정 → 그래픽 '낮음'을 고르면 더 가벼워져요.
- **'서버 경유'** 로 나온다 → 두 컴퓨터가 직접 연결되지 못해 서버를 거치는 중이라 핑이 커요 (회사·학교망, 일부 모바일 핫스팟). 화면이 끊기지 않게 버퍼를 늘려서 보여 주지만, 반응이 조금 늦어요.
- 게임 계산은 방장 컴퓨터가 하므로 **더 좋은 컴퓨터가 방장**을 하는 게 좋아요.

## 기술 메모

- 좀비·목표·문 등 게임 계산은 **방장 브라우저의 웹 워커**에서 초당 30번 돌고, 서버는 두 사람 사이에서 메시지만 전달합니다. 그래서 무료 서버로도 충분해요.
- 가능하면 WebRTC 로 두 브라우저를 직접 연결하고(지연 ↓), 안 되면 서버 웹소켓으로 전달합니다. 받은 위치는 지터 버퍼로 고르게 재생해서, 패킷이 들쭉날쭉 와도 움직임이 끊기지 않게 합니다.
- 그래픽: 48m 구역별로 묶어서 안개에 묻힌 먼 곳·지하/지상 반대편은 그리지 않고, 프레임이 45 아래로 떨어지면 해상도를 자동으로 낮춥니다.
- 자기 움직임은 자기 화면에서 바로 처리하고, 총알 명중은 쏜 사람이 판정합니다.
- 맵은 코드로 쌓은 데이터(`public/js/shared/map.js`)이고, 좀비는 0.5m 격자 위의 흐름장(flow field)을 따라 벽을 돌아 쫓아옵니다.
- 자세한 설계는 [docs/DESIGN.md](docs/DESIGN.md) (길 스포일러 있음).

## 개발

```bash
cd lastboat
npm install
npm start          # http://localhost:3200
npm test           # 시뮬레이션·서버 테스트
node tools/routecheck.mjs   # 단계별로 다음 목표까지 길이 이어지는지 확인
node tools/mapviz.mjs map.png surface   # 맵을 위에서 본 그림(PNG), subway 로 지하
```

혼자 하기 주소 뒤에 `?peace` 를 붙이면 좀비가 공격하지 않는 개발용 모드로 맵을 둘러볼 수 있어요.
