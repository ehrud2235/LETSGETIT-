# 맞은편 — THE OTHER SIDE

> 같은 방, 다른 시간. 벽 너머의 당신은, 누구인가요?

브라우저에서 바로 하는 **2인 협동 3D 방탈출 게임**입니다.
한 명이 방을 만들고 다른 한 명이 **초대코드**로 들어오면, 두 사람은 각자 다른 방에서 눈을 뜹니다.
1인칭으로 방 안을 걸어다니며(WASD + 마우스) 단서를 찾고, 대화창으로 서로의 방을 설명하며 퍼즐을 풉니다.
내 방에서 한 행동이 벽 너머의 방을 바꿉니다.

(두 사람의 정체는 엔딩에서 밝혀집니다. 스포일러는 [`docs/GAME_DESIGN.md`](docs/GAME_DESIGN.md)에 있어요.)

## 🥊 두 번째 게임: 물렁 난투 (`/brawl/`)

같은 서버의 **`/brawl/`** 주소에서 열리는 **4인 물리 난투**입니다. (예: `https://…onrender.com/brawl/`)
말랑한 고멤 캐릭터들이 갱비스트처럼 흐느적거리며 치고받고, 붙잡고, 들어 던져서 경기장 밖으로 떨어뜨립니다.
MMA 버튼 하나로 **태클 → 마운트 → 초크**, **수플렉스**, **리어 네이키드 초크**까지 됩니다.

- **바로 시작**: 봇 3명과 바로 한 판 (설치 없음, 브라우저만)
- **오프라인 대기실**: 한 컴퓨터에서 최대 4명 (키보드 두 벌 + 게임패드 최대 4개), 빈자리는 봇(초보/보통/고수)
- **온라인 방**: 초대코드/링크로 최대 4명. 방장 브라우저가 물리를 계산하고, 다른 사람은 WebRTC로 직접 연결(안 되면 서버 중계)
- 맵 4개: 옥타곤(철창이 떨어짐) · 루석바 옥상(돌풍) · 고멤 공장(컨베이어·크레인·파쇄기) · 비밀 FC 하늘 구장(기우는 경기장·축구공)
- 캐릭터 8명, 각자 패시브 하나 (리치 +20%, 발차기 +50% 같은 식으로 밸런스를 크게 해치지 않게)

| 동작 | 키보드 1 | 키보드 2 | 게임패드 |
| --- | --- | --- | --- |
| 이동 | `W` `A` `S` `D` | 방향키 | 왼쪽 스틱 |
| 왼손 / 오른손 (탭 = 주먹, 꾹 = 잡기) | `J` / `K` (마우스 왼쪽/오른쪽) | `1` / `2` 또는 `,` / `.` | LT / RT |
| 점프 (잡고 있으면 들어 올리기, 떼면 던지기) | `Space` | `0` / 오른쪽 Ctrl | A |
| 발차기 · 박치기 | `L` · `U` | `3` · `4` | B · X |
| MMA 기술 | `F` | `5` / `'` | Y |
| 달리기 · 웅크리기 | 왼쪽 Shift · `C` | `6` · `7` | RB · LB |

휴대폰은 화면의 스틱과 버튼으로 합니다. 자세한 설계는 [`docs/BRAWL_DESIGN.md`](docs/BRAWL_DESIGN.md) 에 있어요.
비공식 팬게임이며, 공식 아바타 그림 대신 직접 만든 캐리커처 모델을 씁니다.

## 친구와 하기 (서로 다른 곳에 있어도 OK)

이 게임은 두 사람이 **같은 주소(URL)** 에 접속해야 합니다. 방법은 두 가지예요.

### 방법 1. 무료로 인터넷에 올리기 — 추천 (터미널 필요 없음)

한 번 올려두면 고정 주소가 생기고, 내 컴퓨터를 꺼도 친구와 언제든 할 수 있어요.

1. 이 코드가 GitHub 저장소에 올라가 있어야 합니다.
2. <https://render.com> 에 GitHub 계정으로 가입합니다.
3. **New + → Blueprint** 를 누르고 이 저장소를 고른 뒤 **Apply** 를 누릅니다. (`render.yaml` 에 설정이 들어 있어요)
4. 몇 분 뒤 `https://the-other-side-xxxx.onrender.com` 같은 주소가 생깁니다. 이 주소를 친구에게 보내면 끝.

알아둘 점: 무료 플랜은 한동안 아무도 접속하지 않으면 서버가 잠들어서, 첫 접속 때 1분 정도 로딩이 걸릴 수 있어요.
서버가 다시 시작되면 진행 중이던 방은 사라집니다. 게임하는 동안에는 연결이 유지되므로 문제없어요.

### 방법 2. 내 윈도우 PC에서 열고 인터넷 링크로 공유하기

공유기 설정 없이, 내 PC를 켜둔 동안만 친구가 들어올 수 있어요.

1. <https://nodejs.org> 에서 **LTS** 버전을 설치합니다. (한 번만)
2. 게임 폴더(압축을 푼 폴더)에서 **`play-online.bat`** 을 더블클릭합니다.
3. 검은 창 두 개가 뜨고, 잠시 뒤 `https://무언가.trycloudflare.com` 주소가 나옵니다.
4. 그 주소를 내 브라우저로 열고, 같은 주소를 친구에게 보냅니다.
5. 게임하는 동안 **검은 창 두 개를 닫지 마세요.** 주소는 실행할 때마다 바뀝니다.

### 개발자용

```bash
npm install
npm start          # http://localhost:3000
npm test
```

`PORT` 환경변수로 포트를 바꿀 수 있고, 상태 확인 경로는 `/healthz` 입니다. 도커가 되는 곳(Fly.io, Railway 등)이라면 `Dockerfile` 을 그대로 쓰면 됩니다.

## 조작

| 동작 | PC | 휴대폰 |
| --- | --- | --- |
| 이동 | `W` `A` `S` `D` (방향키도 가능) | 왼쪽 아래 조이스틱 |
| 둘러보기 | 마우스 (화면을 클릭하면 커서가 잠김) | 화면 드래그 |
| 조사 | `E` 또는 클릭 | 화면 탭 / `조사` 버튼 |
| 소지품 들기 | `1`~`6` (든 채로 조사하면 사용, 다른 소지품을 고르면 조합) | 소지품 탭 |
| 내려놓기 / 읽기 | `Q` / `R` | 버튼 |
| 대화 | `Enter` → 입력 → `Enter` | 아래 대화창 |
| 힌트 | `H` 또는 💡 버튼 | 💡 버튼 |
| 커서 풀기 | `Esc` | — |

한글 입력 상태에서도 WASD 가 그대로 동작합니다(키 위치 기준).

```
server.js            HTTP(정적 파일) + WebSocket(방/초대코드/실시간 동기화)
play-online.bat      윈도우용: 서버 실행 + 인터넷 공유 링크 만들기
render.yaml          Render 무료 배포 설정
Dockerfile           도커 배포 설정
game/logic.js        퍼즐 규칙, 상태, 모든 대사와 엔딩 (서버에서만 실행)
public/index.html    화면 구성
public/style.css
public/js/app.js       로비·HUD·대화·패널·엔딩 흐름
public/js/viewer.js    Three.js 렌더러 + 시선(레이캐스트)으로 물건 고르기
public/js/world.js     3D 방 만들기 (두 방은 치수와 배치가 같고, 색과 물건 상태만 다름)
public/js/controls.js  1인칭 조작 (포인터 잠금, WASD, 충돌, 터치 조이스틱)
public/js/textures.js  캔버스로 그리는 텍스처 (창밖 풍경, 시계, 달력, 그림 등)
public/js/audio.js     Web Audio 로 합성한 효과음과 오르골 멜로디
test/                node --test 로 실행하는 규칙·서버 통합 테스트

brawl/server/rooms.js          물렁 난투 방 서버 (/brawl-ws): 대기실, 경기 시작, 스냅샷·입력 중계와 검증, WebRTC 신호
brawl/public/index.html        물렁 난투 화면 (타이틀·대기실·경기·결과)
brawl/public/js/sim/           물리 시뮬레이션 (브라우저 워커와 Node 테스트에서 똑같이 돌아감)
  sim.js        라운드 규칙, 타격 판정, 탈락, 서든데스
  fighter.js    능동 래그돌 격투가 (11개 몸 부위, 관절, 균형, 주먹·잡기·발차기·박치기·들어 던지기)
  grapple.js    MMA: 태클, 마운트, 서브미션, 수플렉스, 탈출
  maps.js       맵 4개와 함정    bot.js  봇 AI    roster.js  캐릭터·패시브
  snapshot.js   네트워크 이진 형식    worker.js  방장 브라우저의 물리 워커
brawl/public/js/client/        그리기(Three.js)·입력·HUD·소리·온라인 연결
brawl/tools/                   개발용: 봇 경기, 밸런스 측정, 동작 점검 스크립트
```

- 게임 상태는 서버에만 있고, 각 플레이어는 **자기 방의 모습만** 전달받습니다. 개발자 도구로 상대 방이나 정답을 엿볼 수 없어요.
- 새로고침하거나 연결이 끊겨도 같은 브라우저로 돌아오면 이어서 플레이할 수 있습니다.
- 외부 이미지·사운드 파일 없이 모든 그래픽과 소리를 코드로 만듭니다. Three.js 는 npm 패키지에서 서버가 직접 제공합니다(CDN 불필요).
