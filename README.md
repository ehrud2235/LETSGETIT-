# 맞은편 — THE OTHER SIDE

> 같은 방, 다른 시간. 벽 너머의 당신은, 누구인가요?

브라우저에서 바로 하는 **2인 협동 3D 방탈출 게임**입니다.
한 명이 방을 만들고 다른 한 명이 **초대코드**로 들어오면, 두 사람은 각자 다른 방에서 눈을 뜹니다.
1인칭으로 방 안을 걸어다니며(WASD + 마우스) 단서를 찾고, 대화창으로 서로의 방을 설명하며 퍼즐을 풉니다.
내 방에서 한 행동이 벽 너머의 방을 바꿉니다.

(두 사람의 정체는 엔딩에서 밝혀집니다. 스포일러는 [`docs/GAME_DESIGN.md`](docs/GAME_DESIGN.md)에 있어요.)

## 실행하기

Node.js 18 이상이 필요합니다.

```bash
npm install
npm start
```

브라우저에서 <http://localhost:3000> 에 접속합니다.

- 같은 와이파이의 친구는 `http://<내 컴퓨터 IP>:3000` 으로 접속하면 됩니다.
- 포트를 바꾸려면 `PORT=8080 npm start`.
- 테스트: `npm test`

## 조작

| 동작 | PC | 휴대폰 |
| --- | --- | --- |
| 이동 | `W` `A` `S` `D` (방향키도 가능) | 왼쪽 아래 조이스틱 |
| 둘러보기 | 마우스 (화면을 클릭하면 커서가 잠김) | 화면 드래그 |
| 조사 | `E` 또는 클릭 | 화면 탭 / `조사` 버튼 |
| 소지품 들기 | `1`~`6` (든 채로 조사하면 사용, 다른 소지품을 고르면 조합) | 소지품 탭 |
| 내려놓기 / 읽기 | `Q` / `R` | 버튼 |
| 대화 | `Enter` → 입력 → `Enter` | 아래 대화창 |
| 힌트 | `H` 또는 💡 버튼 | 💡 버튼 |
| 커서 풀기 | `Esc` | — |

한글 입력 상태에서도 WASD 가 그대로 동작합니다(키 위치 기준).

## 인터넷에 올려서 친구와 하기

실시간 방 동기화를 위해 작은 Node 서버가 필요합니다(정적 호스팅인 GitHub Pages 만으로는 동작하지 않아요).
웹소켓을 지원하는 아무 Node 호스팅이면 됩니다. 예: Render, Railway, Fly.io.

- 빌드 명령: `npm install`
- 시작 명령: `npm start`
- 서버는 `PORT` 환경변수를 자동으로 사용합니다. 상태 확인 경로는 `/healthz`.

## 구조

```
server.js            HTTP(정적 파일) + WebSocket(방/초대코드/실시간 동기화)
game/logic.js        퍼즐 규칙, 상태, 모든 대사와 엔딩 (서버에서만 실행)
public/index.html    화면 구성
public/style.css
public/js/app.js       로비·HUD·대화·패널·엔딩 흐름
public/js/viewer.js    Three.js 렌더러 + 시선(레이캐스트)으로 물건 고르기
public/js/world.js     3D 방 만들기 (두 방은 치수와 배치가 같고, 색과 물건 상태만 다름)
public/js/controls.js  1인칭 조작 (포인터 잠금, WASD, 충돌, 터치 조이스틱)
public/js/textures.js  캔버스로 그리는 텍스처 (창밖 풍경, 시계, 달력, 그림 등)
public/js/audio.js     Web Audio 로 합성한 효과음과 오르골 멜로디
test/                node --test 로 실행하는 규칙·서버 통합 테스트
```

- 게임 상태는 서버에만 있고, 각 플레이어는 **자기 방의 모습만** 전달받습니다. 개발자 도구로 상대 방이나 정답을 엿볼 수 없어요.
- 새로고침하거나 연결이 끊겨도 같은 브라우저로 돌아오면 이어서 플레이할 수 있습니다.
- 외부 이미지·사운드 파일 없이 모든 그래픽과 소리를 코드로 만듭니다. Three.js 는 npm 패키지에서 서버가 직접 제공합니다(CDN 불필요).
