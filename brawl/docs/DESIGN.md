# 물렁 난투 — 설계 노트

말랑한 캐릭터들이 흐느적거리며 싸우는 4인 물리 난투(갱비스트류)에 MMA 잡기 기술을 더한 웹게임.
스토리는 없고, 맵과 캐릭터 패시브, 그리고 "물리로 우스꽝스럽게 싸우는 맛"이 전부다.

## 왜 웹인가

설치형으로 갈 이유를 따져 봤지만 웹으로 충분했다.

- 물리: Rapier(러스트로 만든 물리엔진)의 WASM SIMD 빌드. 4명 × 11부위 + 맵 물체를 60Hz로 돌려도 한 스텝에 0.3~0.4ms.
- 물리는 **웹 워커**에서 돌아서 화면(Three.js)과 서로 발목을 잡지 않는다. 방장이 잠깐 다른 탭을 봐도 경기는 계속된다.
- 설치 없이 링크 하나로 친구를 부를 수 있다는 점이 "무지성 스트레스 해소" 목적에 더 맞다.

## 격투가: 능동 래그돌

몸은 11개 강체(골반·몸통·머리·위팔/아래팔×2·허벅지/정강이×2)와 구형 관절로 이어져 있다. 애니메이션은 없고, 매 스텝
각 부위에 "이 자세가 되고 싶다"는 목표 회전을 주고 각속도를 섞어서(PD 제어) 흉내 낸다.

- 균형: 골반 아래로 광선을 쏴서 땅 위 0.8m 높이를 유지하는 부력(호버). 땅에 있을 땐 윗몸 중력을 줄여 오뚝이처럼 선다.
- 공중·날아가는 중: 중력을 그대로 받아 완전히 흐느적거린다. 세게 맞으면 잠깐 제어를 끊고 몸이 풀린다.
- 주먹은 손을 목표 지점으로 뻗는 동작, 꾹 누르면 손끝에서 가장 가까운 물체에 관절을 만들어 붙잡는다.
  잡은 채 점프를 누르면 들어 올리고, 떼면 던진다. 난간·턱을 잡으면 매달리고 기어오른다.
- 피해는 부딪힌 순간의 **상대 속도**로 계산해서 **% 로 쌓인다**(머리 1.3배, 팔다리 0.6배). 기절(KO)은 없다.
- 넉백 = 기본 세기 × (1 + % / 100 × 1.25) ÷ 무게. 세기가 일정 이상이면 몸 전체가 풀려 날아가고, 잠깐 뒤 스스로 일어난다.
- 탈락은 오직 경기장 밖으로 떨어졌을 때. 바닥·벽에 처박히는 충격은 소리와 먼지만 크고 % 는 거의 안 올라간다
  (날아간 몸이 부딪혀 또 % 가 쌓이고 또 날아가는 눈덩이 현상을 막으려고).
- 던지기 거리와 잡혔을 때 빠져나오기 어려움도 % 에 비례한다. 낮은 % 에서는 멀리 못 던지고, 높은 % 에서는 쉽게 장외.

## MMA

버튼 하나(MMA)가 상황을 읽고 기술을 고른다.

| 상황 | 기술 |
| --- | --- |
| 서 있는 상대가 2.4m 안 | 태클 → 성공하면 넘어뜨리고 자동으로 마운트 |
| 넘어진 상대 가까이 | 마운트 (올라탄 채 주먹 1.5배) |
| 마운트 중 한 번 더 | 초크 — 버튼을 꾹 누르고 있어야 게이지가 오른다 |
| 손으로 잡은 상대의 정면 | 수플렉스 — 들어 올려 뒤로 꽂는다 (머리·몸통이 낮게 떨어지면 큰 피해) |
| 손으로 잡은 상대의 등 뒤 | 리어 네이키드 초크 |

당하는 쪽은 아무 버튼이나 연타해 빠져나온다. 초크 게이지가 차면 탭아웃: % 가 30 오르고 3초 가까이 몸이 풀려서 들고 던지기 좋은 상태가 된다.

## 캐릭터와 패시브

비공식 팬게임이라 이세계아이돌 멤버는 빼고, 고정 멤버 중심으로 골랐다. 공식 아바타 그림은 쓰지 않고 특징만 딴 캐리커처다.
패시브는 **한 가지 능력만** 조금 올린다(능력치 배율 0.7~1.6).

| 캐릭터 | 패시브 | 효과 |
| --- | --- | --- |
| 우왁굳 | 왁두 박치기 | 박치기 위력 +50% |
| 풍신 | 바람 풍! | 점프력 +30%, 공중에서 천천히 떨어짐 |
| 도파민박사 | 강화인간 | 무게 1.2배 — 맞아도 17% 덜 날아감 |
| 이덕수 할아바이 | 해병대 악력 | 잡기 유지력 +30%, 서브미션 속도 +20% |
| 비밀소녀 | 비밀 FC | 발차기 위력 +50% |
| 해루석 | 칵테일 셰이킹 | 주먹 연타 속도 +35% |
| 뢴트게늄 | 광대 곡예 | 날아가거나 넘어져도 60% 빨리 일어남 |
| 단답벌레 | 벌레 팔 | 팔 길이 +20% |

## 맵

| 맵 | 특징 | 서든데스(75초) |
| --- | --- | --- |
| 옥타곤 | 공중에 뜬 팔각 케이지. 16초부터 13초마다 철창이 하나씩 떨어져 나간다 | 철창 전부 떨어짐 |
| 루석바 옥상 | 난간에 틈, 바 테이블, 들고 던질 수 있는 의자·술통. 16초마다 돌풍 | 7초마다 더 센 돌풍 |
| 고멤 공장 | 가운데 발판 양옆으로 파쇄기를 향해 흐르는 컨베이어, 떨어지는 상자, 매달릴 수 있는 크레인 갈고리 | 벨트가 빨라짐 |
| 비밀 FC 하늘 구장 | 가운데 축을 중심으로 사람이 몰린 쪽으로 기우는 풋살장, 날아다니는 축구공 | 더 크게 기움 |

## 경기 규칙

- 라운드: 카운트다운 3초 → 싸움 → 떨어진 사람은 관전 → 마지막 한 명이 남으면 승리. 다시 살아나지 않는다. 75초부터 서든데스.
- 1·2·3·5승 선취 중 고른다. 혼자면 연습 모드(떨어지면 다시 등장).
- 결과 화면: 준 피해(%), 떨어뜨린 횟수(최근 12초 안에 때린 사람에게 공이 돌아감).
- 맵의 낮은 난간·펜스(공장 발판 턱, 하늘 구장 펜스, 옥타곤 철창)는 살살 밀려서는 안 떨어지고, % 가 높을 때 세게 날아가면 넘어가도록 높이를 맞췄다.

## 화면과 소리

- 타격마다 글자(퍽!, K.O.)를 띄우지 않는다. 먼지·파편과 화면 흔들림만, 세게 날아갈수록 크게.
- 위쪽 카드와 머리 위에 % 를 크게 보여 준다(흰색 → 노랑 → 주황 → 빨강). 초크 게이지와 "연타!" 안내는 조작에 필요해서 남긴다.
- 소리는 전부 둔탁한 "퍽·쿵": 짧은 저음 몸통 소리 + 낮게 거른 잡음. 음높이가 미끄러지는 소리는 쓰지 않는다.
- 배경음은 음악 대신 낮은 북소리와 관중 웅성거림.

## 온라인 구조

```
방장 브라우저                              서버 (/ws)                      참가자 브라우저
┌────────────────────┐   스냅샷 30Hz(이진)   ┌──────────────┐  (중계 필요 시)  ┌────────────────┐
│ 워커: Rapier 60Hz   │ ───── WebRTC 직접 ──────────────────────────────────▶ │ 0.1초 뒤를 보간  │
│ 메인: 그리기·HUD    │ ◀──── 입력(이진) ─────────────────────────────────── │ 입력 60Hz 이하  │
└────────────────────┘ ─ 대기실/신호/이벤트 ▶ │ 방·슬롯 관리 │ ◀─ 대기실 ────── └────────────────┘
```

- 물리는 방장만 계산한다(권한 방장). 참가자는 입력만 보내고, 방장이 보낸 스냅샷을 그린다.
- 스냅샷: 물체 하나에 14바이트(위치 2mm 단위 int16, 회전 int16 쿼터니언). 4명 기준 약 1KB, 30Hz.
- 입력: 사람마다 10바이트 — 이동 방향(카메라 기준을 월드로 바꿔서), 누르고 있는 버튼, **버튼별 누른 횟수**.
  횟수를 보내기 때문에 순서 없는·재전송 없는 채널에서 패킷을 잃어도 "눌렀다"는 사실은 다음 패킷으로 전해진다.
- WebRTC 데이터 채널(순서 없음, 재전송 없음)로 먼저 직접 연결을 시도하고, 안 된 사람에게만 서버가 스냅샷을 중계한다.
- 서버는 입력 패킷이 그 슬롯 주인이 보낸 것인지 확인하고 넘긴다(직접 연결로 온 입력은 방장이 같은 검사를 한다).
- 누가 끊기면 그 캐릭터는 봇이 대신 싸우고, 새로고침해서 돌아오면(세션 토큰) 다시 조종한다.
- 방장이 15초 넘게 끊기면 경기를 멈추고 다른 사람이 방장이 된다.

## 서버

`brawl/server.js` 는 방탈출 게임과 완전히 따로 도는 독립 서버다(자기 `package.json`, 자기 Render 서비스, 다른 주소).
정적 파일과 Three.js·Rapier 파일을 제공하고, `/ws` 웹소켓 하나로 대기실과 중계를 맡는다.

## 테스트

```bash
cd brawl
npm test                        # 시뮬레이션·서버 프로토콜·정적 파일
node tools/botmatch.mjs pitch   # 봇 4명 경기 한 판 로그
node tools/balance.mjs          # 캐릭터별 승률
node tools/probe.mjs grab       # 동작 하나 점검 (stand/walk/jump/duel/grab/throw/tackle/suplex)
```

개발용 화면: `/dev.html?map=factory&bots` — 시뮬레이션을 메인 스레드에서 돌리며 바로 그린다.
