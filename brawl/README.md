# 물렁 난투 — 고멤 4인 물리 난투

말랑한 고멤 캐릭터들이 갱비스트처럼 흐느적거리며 치고받고, 붙잡고, 들어 던져서 **경기장 밖으로 날려 버리는** 브라우저 게임입니다.
설치 없이 링크만 있으면 되고, 한 컴퓨터에서 최대 4명, 온라인으로 최대 4명이 할 수 있어요.

비공식 팬게임이며, 공식 아바타 그림 대신 직접 만든 캐리커처 모델을 씁니다.

## 규칙

- 맞을수록 **%** 가 쌓이고, % 가 높을수록 같은 공격에도 **더 멀리 날아갑니다** (대난투식).
- 맞아서 쓰러지는 건 잠깐뿐이에요. **탈락은 오직 경기장 밖으로 떨어졌을 때** 뿐이고, 다시 살아나지 않습니다.
- 떨어진 사람은 남은 사람들의 싸움을 **관전**하고, **마지막 한 명**이 남으면 라운드 승리. 정해 둔 승수(1·2·3·5승)를 먼저 채우면 우승.
- % 가 높은 사람은 잡혀도 잘 못 빠져나오고, 던지면 멀리 날아갑니다.
- 75초가 지나면 서든데스: 맵이 더 위험해집니다.
- 혼자 하는 연습 모드에서만 떨어져도 다시 나옵니다.

## 조작

| 동작 | 키보드 1 | 키보드 2 | 게임패드 |
| --- | --- | --- | --- |
| 이동 | `W` `A` `S` `D` | 방향키 | 왼쪽 스틱 |
| 왼손 / 오른손 (탭 = 주먹, 꾹 = 잡기) | `J` / `K` (마우스 왼쪽/오른쪽) | `1` / `2` 또는 `,` / `.` | LT / RT |
| 점프 (잡고 있으면 들어 올리기, 떼면 던지기) | `Space` | `0` / 오른쪽 Ctrl | A |
| 발차기 · 박치기 | `L` · `U` | `3` · `4` | B · X |
| MMA 기술 (태클·마운트·초크·수플렉스) | `F` | `5` / `'` | Y |
| 달리기 · 웅크리기 | 왼쪽 Shift · `C` | `6` · `7` | RB · LB |

휴대폰은 화면의 스틱과 버튼으로 합니다.

## 인터넷에 올리기 (Render 무료)

저장소 최상위의 `render.yaml` 블루프린트에 이 게임이 **`mullung-brawl`** 이라는 별도 서비스로 들어 있어요.

- 이미 블루프린트로 방탈출 게임을 올렸다면: Render 대시보드 → Blueprints → 이 저장소 → **Sync** (또는 Manual Sync) 를 누르면 새 서비스가 추가됩니다.
- 직접 만들 때는: **New + → Web Service** → 이 저장소 → **Root Directory 에 `brawl`** → Build `npm ci --omit=dev`, Start `npm start`.

몇 분 뒤 `https://mullung-brawl-xxxx.onrender.com` 같은 새 주소가 생깁니다. 방탈출 게임과는 주소가 다릅니다.
무료 플랜은 서비스 여러 개가 한 달 750시간을 나눠 쓰지만, 아무도 없을 때는 잠들어서 시간이 거의 안 줄어요.

## 개발

```bash
cd brawl
npm install
npm start      # http://localhost:3100
npm test
node tools/botmatch.mjs factory   # 봇 4명 경기 한 판 로그
```

개발용 화면: `/dev.html?map=pitch&bots` — 시뮬레이션을 메인 스레드에서 돌리며 바로 그립니다.
설계는 [`docs/DESIGN.md`](docs/DESIGN.md) 에 있어요.

```
server.js              정적 파일 + /ws 웹소켓 (독립 서버)
server/rooms.js        방·대기실·경기 시작, 스냅샷·입력 중계와 검증, WebRTC 신호
public/js/sim/         물리 시뮬레이션 (브라우저 워커와 Node 테스트에서 똑같이 돌아감)
public/js/client/      그리기(Three.js)·입력·HUD·소리·온라인 연결
tools/                 봇 경기, 밸런스 측정, 동작 점검
test/                  시뮬레이션·서버 테스트
```
